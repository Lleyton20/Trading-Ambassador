# Trading Ambassador — dashboard

React + TypeScript + Vite frontend for the Trading Ambassador API. See
the [root README](../README.md) for setup, the full feature list, and
how this fits into the rest of the project.

```bash
npm install
npm run dev
```

Requires the backend running at `http://127.0.0.1:8000` (see
`vite.config.ts` for the dev proxy).
